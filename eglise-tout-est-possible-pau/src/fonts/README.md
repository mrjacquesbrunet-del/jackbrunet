# Police Loubag (licence requise)

Loubag n'est pas une police libre : elle nécessite une licence pour un
site public. Une fois les fichiers obtenus :

1. Déposer ici les fichiers, ex. `Loubag-Bold.woff2` (et
   `Loubag-Regular.woff2` si besoin).
2. Dans `src/app/layout.tsx`, remplacer le bloc `Righteous` par le bloc
   `localFont` indiqué en commentaire juste au-dessus.

En attendant, le site utilise **Righteous** (Google Fonts), l'équivalent
libre le plus proche : géométrique, arrondi, rétro-stylé.
