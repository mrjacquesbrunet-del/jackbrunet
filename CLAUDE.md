# Préférences de travail — projet Jack Brunet

## Règles de collaboration (à respecter toujours)

- **SQL toujours donné directement dans le chat.** Chaque fois qu'une
  modification nécessite d'exécuter du SQL (migration Supabase, trigger,
  fonction, RLS…), fournir le bloc SQL **complet et prêt à copier-coller**
  directement dans la réponse du chat, accompagné de la démarche
  (Supabase → SQL Editor → Run). Ne jamais renvoyer Jack chercher un
  fichier `.sql` sur GitHub ou ailleurs — c'est lui qui exécute le SQL,
  il doit l'avoir sous les yeux. (Le fichier `.sql` peut aussi être commité
  au dépôt pour l'historique, mais le contenu doit **en plus** apparaître
  dans le chat.)

- **Interface sans emojis.** Toujours des icônes en trait de la charte
  dans l'interface, pas d'emojis. (Exception explicite : les réactions aux
  commentaires du mur de prière, où Jack a choisi les emojis 🙏 ❤️ 🕊️ 🙌 ✨.)

- **Tutoiement** dans toutes les communications avec Jack.

- **Ne jamais afficher/coller de secrets** (clés API Capgo, Brevo, Stripe,
  OneSignal…) dans le chat, les commits ou le code.
